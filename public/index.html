Surf MCP connector

Not a website — an MCP server for Claude.

This host answers the Model Context Protocol at:

/mcp

To use it, add that full URL as a custom connector in Claude under Settings → Connectors → Add custom connector. Claude can then answer questions like “where’s the best surf near Newquay tomorrow morning?” or “which beach is nicest to sit on this afternoon?”

Forecast data comes from the surf API this connector wraps, which is built on Open-Meteo’s marine and weather models plus Stormglass tides.
